## Private signing (interface only, disabled by default)

`private_signature` implements deterministic, domain-separated `atto-private-guest-attestation-v1` signing-statement bytes binding exact repository, commit/tree, fixture hash, GitHub run/attempt/job, artifact SHA-256, verifier-issued challenge nonce, approved signer workflow, claimed runner identity, backend and feature. It offers `PrivateSigningService` for future independently-administered KMS/HSM integration, but **SigningDisabled** is the only production signer supplied. The Rust verifier can check a 64-byte Ed25519 detached signature using OpenSSL against **exact pinned PEM SHA-256**, explicit key validity dates and revocation. No keys, cloud secrets, signing API access or public transparency-log uploads are created. Rust tests generate ephemeral TEST keys, then reject substituted artifacts, tree/run/job/challenges, wrong runner/signer, wrong public keys, expired/revoked keys, and forged signatures.

**Trust limitation:** `runner_identity` is inside the signed statement; cryptography alone does not verify that a runner was truly trusted. The independent signing authority must attest that property before signing. A signature over an unreviewed workflow claim is NOT guest certification.
